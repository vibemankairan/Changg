DoBu Martial Arts — Self-Contained Website

This folder contains the complete website program and all image assets required by the pages.

Files:
- HTML pages: index.html, classes.html, timetable.html, membership.html, account.html, about.html, community.html, 404.html
- CSS: styles.css
- JavaScript: script.js
- Images: dobu-belt-knot-logo.png, dobu-hero-training.jpg, dobu-karate-practice.jpg, dobu-kids-class.jpg

IMPORTANT:
- Keep all files in this same folder.
- Image references use local relative filenames, so images do not depend on an online image service.
- The website does not require an npm install, build step, framework, or external font download.
- Open index.html in a browser to view the site.
- For best testing of navigation and browser behaviour, serve the folder with a simple local web server (for example VS Code Live Server).
- Member Area and Community features are demonstration prototypes using browser localStorage; they are not a real secure login/database/social service.
